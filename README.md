# AI-SHAPS – Object Oriented Analysis and Design

## Project Title

AI-Enabled Smart Healthcare Appointment and Patient Support System (AI-SHAPS)

## Course

* Course Code: CSA11
* Course Name: Object Oriented Analysis and Design

## Project Description

AI-SHAPS is a centralized healthcare management system that connects patients, doctors, reception staff, laboratory staff, pharmacy staff, and administrators. The system supports online appointment booking, AI-based doctor recommendations, prescription management, laboratory report updates, and appointment reminders.

## Features

* Patient Registration
* Doctor Search
* Appointment Booking
* AI-Based Doctor Recommendation
* Prescription Management
* Laboratory Report Upload
* Pharmacy Status Update
* Appointment Reminders
